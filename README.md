# ラリーカット

卓球の試合動画から、ラリーしているところだけを取り出して1本の動画にする道具。
動画はどこにも送られない。すべてブラウザの中だけで動く。

## 配るもの

| ファイル | 中身 |
|---|---|
| `index.html` | これ1枚で完結。ラリーを手で記録して、動画を書き出す |
| `privacy.html` | プライバシーポリシー。アクセス解析を入れたので必須 |

**アップロードするのはこの2枚だけ。**「ラリーを切り取る」（判定器にまかせる）はまだ準備中なので、
公開フォルダには入れていない。作った人は URL に `?dev` を付けると行ける。

## 使い方

1. 動画を選ぶ（横向き・回しっぱなしで撮ったもの）
2. ラリーの間だけ押しっぱなし
3. ラリーだけの動画を書き出す

## しくみ

印をつけた区間を順番に再生し、その画面を録画して1本の動画にする。
ブラウザに「動画を切ってつなぐ」部品が無いため、この方法をとっている。
書き出しには、残る長さと同じだけ時間がかかる。
