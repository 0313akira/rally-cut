# ラリーカット

卓球の試合動画から、ラリーしているところだけを選び出して続けて再生する道具。
動画はどこにも送られない。すべてブラウザの中だけで動く。

## ファイルの役割

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `model.js` | 学習ずみ判定器の重み（82個の数字） |
| `score.js` | 動きの数字 → ラリーらしさの点数 → 区間 |
| `app.js` | 動画を選ぶ・解析する・再生する・確かめる |
| `grow.js` | 自分の動画で判定器を育てる（この端末の中だけ） |

## しくみ

1. 動画を1秒に4コマ読み取り、姿勢検出（MoveNet）で選手の関節を見つける
2. 手首・肘・足首などの速さを、体の大きさで割って記録する（カメラの距離に左右されないように）
3. その数字を判定器にかけて、コマごとに「ラリーらしさ」を0〜1で出す
4. 点数をならして、上位◯%を残し、短すぎる区間を捨てて、ラリーの区間にする

## 判定器について

- ロジスティック回帰（重み82個、7KB）
- 学習データ：8本・47分ぶんの試合動画に人手で正解をつけたもの
- 初見の動画での成績：ラリーを80%拾える／区間の正解率86%

## 動かし方

`index.html` をブラウザで開くだけ。インターネットにつながっている必要がある
（姿勢検出のモデルを読み込むため）。
